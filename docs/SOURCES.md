# Focused source audit

Checked October 15, 2026, America/Los_Angeles. This extends the [earlier 14-system survey](https://github.com/aarnavbhat23/nature-compute-lab/tree/research/repair-driven-development/research/nature-learning-survey); it does not claim an exhaustive novelty search.

- **R1 — Lau et al., Whi3 mnemon association with endoplasmic reticulum membranes confines the memory of deceptive courtship to the yeast mother cell. Current Biology (2022).** [Primary full-text record](https://pmc.ncbi.nlm.nih.gov/articles/PMC8938615/), [DOI](https://doi.org/10.1016/j.cub.2022.01.002). Indexed primary discussion was readable; direct page presented a browser challenge. Supports persistent assembly-associated memory and compartmental restriction. Does not demonstrate AM-0's prediction-error rule or a general-purpose learner.
- **R2 — Learning Polynomial Functions by Feature Construction. Machine Learning Proceedings 1991, pp. 208–212.** [Publisher](https://www.sciencedirect.com/science/chapter/edited-volume/abs/pii/B9781558602007500453), [DOI](https://doi.org/10.1016/B978-1-55860-200-7.50045-3). Publisher abstract indexed and read; direct fetch 403. It describes regression plus error-guided formation of products of features. Direct collision with generic claims of learning through combination of primitive features.
- **R3 — Agarwal, Beygelzimer, Hsu, Langford and Telgarsky, Scalable Non-linear Learning with Adaptive Polynomial Expansions. NeurIPS (2014).** [Primary paper](https://papers.nips.cc/paper_files/paper/2014/file/4816828eae320da8a286ceb2e70bbeac-Paper.pdf), [abstract](https://papers.nips.cc/paper_files/paper/2014/hash/4816828eae320da8a286ceb2e70bbeac-Abstract.html). Read algorithm and related-work sections. Learns a growing polynomial feature set with online updates and explicit computation/prediction tradeoffs. AM-0 is not a reproduction; the paper's guarantees are not inherited.
- **R4 — Bartlett and Louapre, Provenance of Lyfe: Chemical Autonomous Agents Surviving through Associative Learning. Physical Review E (2022).** [Author preprint full text](https://arxiv.org/html/2210.05227v1), [published DOI](https://doi.org/10.1103/PhysRevE.106.034401). Read network construction and short/long memory equations. Establishes chemical associative learning as prior art, not general intelligence. No biological experiment is reproduced here.
- **R5 — Poole, Ouldridge and Gopalkrishnan, Autonomous learning of generative models with chemical reaction network ensembles. Journal of the Royal Society Interface (2025).** [DOI](https://doi.org/10.1098/rsif.2024.0373), [PubMed](https://pubmed.ncbi.nlm.nih.gov/39837479/). Primary abstract/indexed evidence in the earlier audit; current direct PubMed request returned no body. Evidence that autonomous chemical learning has precedents; not used to claim exact equality to AM-0.
- **R6 — Kivinen and Warmuth, Exponentiated Gradient versus Gradient Descent for Linear Predictors. Information and Computation (1997).** [DOI](https://doi.org/10.1006/inco.1996.2612). Bibliography identified, primary publisher fetch unavailable this turn. Included as a comparison target, not evidence that AM-0 equals EG. Our exact reduction is derived in this repository without relying on this access-limited source.
- **R7 — Heistinger et al., Plasticity of genetic regulation during cellular learning. bioRxiv preprint (2026).** [DOI](https://doi.org/10.64898/2026.05.27.728101), [primary monthly archive](https://connect.biorxiv.org/archive/2026-05). Existence/title confirmed; full text still inaccessible. Requires follow-up before making claims that Whi3 alone explains present cellular-learning evidence. It is not used to justify AM-0's update rule.

Representative executed search queries: `online learning adaptive polynomial feature construction multiplicative weights sparse interactions`; `chemical reaction network learning multiplicative weights conservation mirror descent`; `Whi3 memory confinement ER barriers cellular learning genetic regulation 2026 Heistinger`; `exponentiated gradient versus gradient descent linear predictors Kivinen Warmuth 1997`; `Scalable Nonlinear Learning adaptive polynomial expansions 2014`; exact-title query for the 2026 genetic-plasticity preprint. Some results were inaccessible or secondary; only primary support is used for substantive claims above.

Absence of an exact match in these searches would not prove novelty. The strongest present conclusion instead comes from the explicit algebraic reduction.
