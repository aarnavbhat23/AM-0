# AM-0: conservative assembly exchange

Status: complete software rule for a **falsification prototype**, not a validated biological mechanism or a new model family. The novelty audit already identifies substantial reductions. We run only a limited diagnostic before deciding whether to invest in a different rule. No ASI claim follows.

## Natural starting point and engineering boundary

Persistent molecular assemblies can store a cell's history; compartment boundaries can restrict propagation. Our first abstraction asks whether learning by assembling a finite supply of reusable components offers anything beyond ordinary feature learning. Whi3 motivates persistence and confinement, **not** a numerical prediction-error signal, a polynomial feature grammar, or our controller. Those are explicit engineering choices.

A component represents one observable history coordinate. An assembly represents co-activation of at most two components. Its two conformations contribute opposite signs to a fixed output. An error can dissolve the opposing conformation and grow the supporting conformation, using the released components. New assemblies are admitted only when their accumulated correlation with error warrants a slot. This is the simplest complete rule we could audit; the audit does not establish the more ambitious reusable-operator architecture.

## Observations and timing

At time t, observe two inputs u[t] in [0,1]^2 and the previous measured response y[t-1]. Keep input traces h_fast and h_slow with decay factors 0.5 and 0.9, respectively. Each is updated from u[t] before prediction. Encode

z[t] = (1, 2u[t]-1, 2h_fast[t]-1, 2h_slow[t]-1, clip(y[t-1], -1, 1)).

There are eight coordinates, including the constant. This fixed encoder is supplied to all main controls and is charged as state. The generator's hidden state, coefficients, regime and future inputs are never passed to a learner. Histories are reset between independent sequences. Learned assemblies are retained across training sequences. Test sequences update history from observed past responses but never update learned parameters: this is **one-step, teacher-forced prediction**, not autonomous long-horizon rollout.

The finite assembly catalogue contains the constant, seven single coordinates, and unordered degree-two products of the seven nonconstant coordinates (including squares): 36 features. For assembly a, phi_a(z) is the product of its coordinates. Let N[i,a] count occurrences of component i, including 2 for squares. The constant uses component 0. The feature catalogue is generated by the declared grammar, not inferred from biology. Learning changes its active support, not the grammar itself.

## State and initialization

- Two nonnegative concentrations b_plus[a], b_minus[a] for each possible assembly.
- One free-component amount c[i] per coordinate, initially M[i] = 4.
- An active mask; initially the eight constant/singleton features are active.
- A signed error-correlation trace s[a], initially zero, for **every** possible feature. Inactive candidates therefore cost memory and arithmetic; they are not free search.
- Update counter t, initially zero. At most K = 20 active assemblies.

Closed-pool accounting is

$$c_i+\sum_a N_{ia}(b_a^++b_a^-)=M_i.$$

The numerical pilot stores the entire fixed catalogue and arrays. The active-slot limit bounds participation, not allocated bytes. We report both. Model state includes all arrays, metadata, history state and Python object overhead separately from dataset storage and temporary workspace.

Prediction is the fixed readout

$$\hat y=\sum_{a\in A}(b_a^+-b_a^-)\phi_a(z).$$

No trained neural encoder, readout, backpropagation or external rule-search model is used. This absence alone is not evidence of novelty.

## Complete update after the true response arrives

1. Compute e = y - y_hat. Let e_c = clip(e, -2, 2). Update **all** candidate scores s <- 0.97 s + 0.03 e_c phi. This is an explicit global error broadcast and an exhaustive local-feature correlation calculation. It is not autonomous biochemical credit assignment.
2. Every 16 labels, consider the inactive feature with largest abs(s). Break ties by catalogue index. If its score exceeds 0.005, activate it if there is a free slot. Otherwise compare it to the active nonsingleton with smallest abs(s); replace that feature only if the candidate's score exceeds 1.1 times the incumbent's score plus 0.005. Singletons cannot be evicted. Before eviction dissolve **both** conformations, returning N[:,a] times their total amount to the free pool. Newly admitted features start with zero concentration. Do not relabel a live assembly in place.
3. For each active feature define h_a = eta e_c phi_a and d_a = min(abs(h_a), 1). If h_a >= 0, dissolve d_a b_minus[a]; otherwise dissolve d_a b_plus[a]. Release all components from these extents simultaneously. Let the remaining pools be c_star and concentrations b_star.
4. Compute the availability of each active assembly g_a = product_i (c_star[i] / M[i]) ** N[i,a]. For numerical depletion, a free fraction <= 1e-12 is treated as zero availability; its amount is not removed from accounting. Raw growth demand is v_a = abs(h_a) g_a. Compute D_i = sum_a N[i,a] v_a. Use a shared limiter alpha = min(1, min_{i:D_i>0} c_star[i] / D_i). A tiny floating-point safety margin is applied only when a pool is binding.
5. Grow alpha v_a in b_plus if h_a >= 0, otherwise in b_minus. Subtract alpha D from c_star. Inactive concentrations remain exactly zero.

All losses and predictions are measured before that label's update. There is no randomized inference or learning step. Experimental generators use pseudorandom independent systems; that does not make the learner a stochastic architecture.

## Persistence, correction, compartments and transfer

Without new labels, concentrations do not change. Prediction alone cannot erase a memory. Contradictory outcomes dissolve opposing conformations. Slot replacement removes a complete feature, and can forget other contexts: no guarantee of continual-learning retention is claimed.

AM-0 uses **one compartment**. This is a deliberate gate: if the elementary rule is an ordinary feature learner, adding compartments does not establish a new primitive. The general wrapper can partition samples using a declared function q(history), hold separate copies of the state, and transfer a chosen assembly by conservative disassembly/reassembly across pools. With fixed routing and a chosen transfer policy, that is a model bank; no learned routing or scientifically justified transfer rule is implemented or claimed here. Testing those unresolved mechanisms belongs to a later candidate, only if warranted.

## Positivity and conservation

Each dissolution removes at most the amount present and returns exactly the constituent amounts. Each growth consumes alpha D_i <= c_star[i]. Thus nonnegativity and every component total are preserved in exact arithmetic. The limiter is a **global numerical allocation step**, not a demonstrated local physical reaction. Component conservation is not an energy/detailed-balance proof, and numerical mass is not CPU memory or metabolic energy.

The two-conformation representation has cancellation: two large opposing pools can yield a small prediction while consuming resources. This may impede learning. We do not secretly annihilate both rails or refill pools to improve a result.

## Cost and scope

For d base coordinates and degree at most two, catalogue size is 1+(d-1)+(d-1)d/2. Dense implementation costs O(dF) per update and O(dF) storage for incidence plus O(F) concentrations/scores/masks. There is no scalability claim beyond this finite catalogue. Increasing maximum degree is combinatorial. The learner has no sequence design, causal-discovery, active experimentation, uncertainty estimation or general reasoning capability.
